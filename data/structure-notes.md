# Data Structure Notes

## Leaders
- Each leader has an ID
- A leader can be active or inactive

## Songs
- Each song can have multiple tags
- Tags may include opening, praise, worship, ministry, victory
- YouTube links are optional
- Song title is required

## Weekly Services
- Every Sunday service gets its own record
- A leader can have a different key for the same song
- Old services should stay archived
- New weeks should not erase old weeks
