Project Stack & Roadmap

Built with a modern web stack

This project is one of my hobby builds. I am using it to show frontend structure, backend data handling, deployment flow, and the features I plan to add next.

Frontend

UI, layout, and navigation

HTML, CSS, and JavaScript with a custom mixer-inspired theme, reusable page sections, calendar UI, cards, tabs, and responsive layout work.

HTML5 CSS3 Vanilla JS Responsive UI Tabbed navigation

Backend / Data

Shared database and service logic

Supabase Postgres stores songs, leaders, services, and service song rows. Row Level Security and RPC functions support shared church planning data.

Supabase Postgres RLS RPC Realtime-ready

Deployment

Online publishing and automatic updates

The site is deployed through Vercel and connected to GitHub, so every push from VS Code can update the live version automatically.

Vercel GitHub Auto deploys HTTPS Preview builds
